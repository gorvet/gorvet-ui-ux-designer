# Changelog

## 1.1.0 - 2026-10-01

- Promoted `gorvet-ui-structure-design` into a true UI architecture + visual structure skill.
- Added architecture-before-styling and structure-only passes.
- Added anti-AI preflight before implementation.
- Expanded anti-AI detection for repeated eyebrow/title/subtitle/card formulas, CTA panels, decorative completion, modern-UI effect bundles, pills, giant type, glass, gradients, hover-lift and reveal-on-scroll defaults.
- Added motif discipline: prefer a small coherent visual vocabulary over unrelated premium effects.
- Added explicit reference decomposition so brand references transfer principles rather than superficial motifs.
- Strengthened project-context surface/discoverability classification.
- Made accessibility baseline apply to human-facing UI.
- Made frontend SEO analysis apply to public/indexable surfaces.
- Made Visual QA use the strongest available evidence and include anti-template review.
- Made Quality Audit a completion gate for substantial new/redesigned UI and empowered it to require simplification/restructure before delivery.
- Updated pipeline documentation and README architecture.
- Removed dependency on editable templates inside the installed package; project specifications remain external inputs.
